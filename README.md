# MERN Stack Application 🚀

This is a full-stack **MERN (MongoDB, Express, React, Node.js)** application developed as a standalone project.  
The backend uses **MongoDB Atlas (cloud database)** for data persistence and follows industry-standard project structure and practices.

---

## 🔑 Key Highlights

- Completely independent MERN project
- MongoDB Atlas cloud database
- RESTful API architecture
- Environment-based configuration
- Scalable and modular folder structure

---

## 🛠 Tech Stack

### Frontend
- React
- HTML5, CSS3, JavaScript
- Axios / Fetch API

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose ODM

### Tools
- npm
- Git & GitHub
- Postman (API testing)
